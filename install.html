Install Confinium Mono

Download the variable font package from GitHub Releases.

Browse releases, notes and checksums.

Desktop

Unzip ConfiniumMono-Variable.zip and open the desktop folder. One TTF covers weights 100–700. Remove any older copy before updating.

  • Windows 10/11: Right-click the TTF and select Install (under Show more options if needed). Install for all users requires administrator access.
  • macOS: Double-click the TTF and choose Install in Font Book.
  • Linux (Fontconfig): From the root of the extracted package, run:
mkdir -p ~/.local/share/fonts/confinium-mono
cp desktop/ConfiniumMono-Variable.ttf ~/.local/share/fonts/confinium-mono/
fc-cache -f ~/.local/share/fonts/confinium-mono

Reopen your editor or terminal. Select Confinium Mono Variable Repertoire and start at weight 400.

Self-host on the web

Copy the WOFF2 from web/ and the included OFL.txt to your site's fonts folder. Adjust the URL for your deployment:

@font-face {
  font-family: "Confinium Mono Web";
  src: url("/fonts/ConfiniumMono-Variable.woff2") format("woff2");
  font-style: normal;
  font-weight: 100 700;
  font-display: swap;
}
pre, code, kbd, samp { font-family: "Confinium Mono Web", monospace; }

Serve the file as font/woff2 and enable CORS if hosting on a different origin. Inspect the rendered font at weights 400 and 700 in browser developer tools.

# Security policy

Confinium Mono is a design study. Please report security issues in the current fonts, build tools or specimen site using [GitHub private vulnerability reporting](https://github.com/Scetrov/confinium-mono/security/advisories/new). Do not include sensitive material or exploit details in a public issue.

Include the affected file or commit, the environment, and the observed impact. Use [GitHub Issues](https://github.com/Scetrov/confinium-mono/issues) for ordinary rendering bugs and design feedback.

A [project-scoped security.txt](https://scetrov.github.io/confinium-mono/.well-known/security.txt) is also available on the specimen site. Renew its `Expires` date before it lapses.

# Lowercase foundations

Isolated Grid Bold study: `n o h p d b q`. The 560-unit x-height leaves a
280-unit counter between the two 140-unit bars. Ascenders meet the 800-unit
caps, descenders reach −200, and all glyphs retain the 800-unit advance.
Compare `non noon hoop bond pod` in [the proof](index.html).

From the repository root, use `uv run python scripts/lowercase_study.py build`
to compile the editable UFO, then `proof` to refresh the standalone page.
`draw` regenerates the study UFO from Grid and **overwrites study edits**.

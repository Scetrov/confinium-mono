# Pinned Grid Bold reference

This UFO and TTF are byte-for-byte copies of the 38-codepoint Grid Bold
baseline available at commit `98f783a`. They preserve the inputs used by the
Hollow, Lowercase Foundations, Punctuation, and A/V Midline Knees studies.
They are not the pre-promotion centred-Q font; the [Q-tail study](../q-tail/index.html)
labels that missing comparison as a reconstruction.

Verify this reference from the repository root:

```sh
sha256sum -c studies/grid-token-bold/reference/SHA256SUMS
```

Do not refresh this reference when live Grid changes. For another comparison,
add a new, named snapshot. Keep the older source, binary, and capture together.

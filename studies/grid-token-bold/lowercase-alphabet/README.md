# Full lowercase alphabet · isolated Grid Bold study

Extends the [foundation UFO](../lowercase/) with `a c e f g i j k l m r s t u v w x y z`.
The 560-unit x-height, 800-unit advance, and 160-unit primary stems carry through;
`m` uses three 128-unit stems to keep both apertures open. Compare `rn` and `m`,
`Il1`, and the single-storey `g` in the [embedded proof](index.html).

Run `uv run python scripts/lowercase_alphabet.py build` to compile the editable
UFO, then `proof` to update the page. `draw` regenerates only this study's UFO
from the foundation source and overwrites edits to the alphabet UFO.
